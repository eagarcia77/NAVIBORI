# NAVIBORI XR

**Puerto Rico Spatial Experience Platform**

NAVIBORI XR is a multi-venue spatial experience platform for Puerto Rico. It combines interactive mapping, indoor/outdoor wayfinding, accessibility, events, commerce, digital twins, AR, VR, and AI-assisted exploration.

## Pilot 001
**Mercado Metropolitano de Juana Díaz, Puerto Rico**

## Product modules
- NAVIBORI Maps — interactive 2D/3D mapping
- NAVIBORI Wayfinding — route graph and accessible routing
- NAVIBORI AR — augmented-reality navigation and discovery
- NAVIBORI VR — immersive exploration
- NAVIBORI Twin — digital-twin data layer
- NAVIBORI AI — spatial concierge and itinerary generation
- NAVIBORI Pulse — privacy-aware analytics
- NAVIBORI Studio — spatial CMS for municipalities and venues

## Technology foundation
- Next.js 16
- React 19
- TypeScript
- MapLibre GL JS
- PostgreSQL + PostGIS / Supabase (planned)
- Three.js / WebXR (planned)
- PWA-first architecture

## Development
```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Architecture principle
A single canonical spatial model should power the 2D map, 3D digital twin, AR, VR, routing, accessibility, and AI experiences.
