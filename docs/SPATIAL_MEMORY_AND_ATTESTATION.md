# Spatial Memory + Reality Attestation

## Spatial Memory
NAVIBORI should explain how a place changed over time using published, provenance-backed events.

Examples:
- created
- updated
- moved
- closed
- reopened
- published

Navi Time Echo can narrate only events present in this timeline.

## Reality Attestation
Before enabling higher-risk spatial experiences, NAVIBORI evaluates readiness:

### Map-ready
- published dataset
- version identity
- verified provenance
- integrity hash verified

### Route-ready
Map-ready plus:
- verified route graph
- verified accessibility metadata

### Immersive-ready
Route-ready plus:
- compatible device
- explicit consent

## Rule
AR/VR capability alone is not sufficient for immersive readiness.
