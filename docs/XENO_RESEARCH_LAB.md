# NAVIBORI XENO Research Lab

## Ground rule
There is no verified extraterrestrial technology available to integrate. XENO uses "extraterrestrial" as a design target: capabilities that feel radically beyond conventional mapping, implemented with real terrestrial technologies where possible.

## XENO stack

### Neural Reality Mesh
Use on-device inference (WebNN where available, WebGPU/Worker fallbacks) to classify context and compile an appropriate experience locally.

### Quantum-Inspired Route Synthesizer
Use classical multi-objective optimization inspired by quantum search metaphors. This is not quantum computing and must never be marketed as such.

### UWB Anchor Mesh
Native companion apps may use Ultra Wideband APIs for high-precision distance/direction. The web application consumes only normalized positioning events through a bridge. QR remains the universal fallback.

### Photonic Portal
Use Gaussian splatting / 360 capture / WebGPU to produce photoreal remote-place portals. The visual capture is never authoritative route geometry.

### Reality Compiler
Canonical spatial data + semantic context + temporal state + capability matrix + accessibility preferences → best output mode.

### Zero-Knowledge Spatial Proofs
Research whether a visitor can prove "I completed this quest" or "I visited this venue" without disclosing a centralized complete location trail.

### RF Ghost Vision
Dedicated mmWave/RF hardware may estimate aggregate occupancy without cameras. This is a research-only path with strict privacy thresholds and no individual identification.

### Lightfield Adapter
Keep render output renderer-agnostic so future glasses-free 3D/light-field displays can consume NAVIBORI scenes.

### Ambient Agent Swarm
Specialized agents may propose actions, but every action remains typed and passes through Reality Firewall.

### Venue Causality Simulator
Simulate what-if operational scenarios before deployment: closure, booth layout, event load, route changes.

## Hard boundary
XENO research must never:
- claim alien origin;
- replace validated accessibility/emergency data;
- identify people from RF/camera sensing;
- bypass user consent;
- publish predictive output as fact;
- create authoritative geometry from generative AI.

## Objective
Make NAVIBORI feel decades ahead while remaining technically honest, auditable and safe.
