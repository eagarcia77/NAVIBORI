# XENO Audit v3 — Reality Aura, Neural Field and Dimensional Portals

## Reality Aura
A venue or POI can expose a visual/sonic state derived only from published facts or clearly labeled prediction.

Priority:
1. operational truth
2. active event
3. accessibility
4. cultural semantics
5. approved prediction
6. neutral physical reality

Prediction must never visually masquerade as fact.

## Spatial Neural Field
A local inference layer chooses presentation/context assistance.

Execution preference:
WebNN → WebGPU → Worker CPU → disabled.

Hard rules:
- sensor inference requires explicit consent;
- raw sensor data is not retained by default;
- neural output cannot mutate authoritative spatial geometry;
- emergency/accessibility facts remain canonical-data governed.

## Dimensional Portal Engine
A portal may render:
- 360 panorama;
- digital Twin;
- Gaussian Splat research capture.

Portal imagery is presentation, not routing geometry.
