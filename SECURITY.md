# Security Policy

NAVIBORI XR handles spatial, venue, merchant and potentially location-derived information. Security and privacy are product requirements.

## Rules
- Never commit secrets, service-role keys or private credentials.
- Client applications may use only public/anon credentials designed for client exposure.
- Administrative data access must be enforced server-side and through database policies.
- Precise user location must be opt-in and minimized.
- Individual location history should not be retained unless a validated feature explicitly requires it.
- Emergency routing must use validated safety data and must not be improvised by generative AI.

## Reporting
Do not publish suspected vulnerabilities in public issues. Contact the repository owner privately.
